# ShadowChat : "Messagerie privée et anonyme en réseau local"
Ce dépôt contient les ressources et le code source pour le développement d'une application de messagerie anonyme en réseau local, intégrant des protocoles de cryptage pour la sécurité des données. Projet pensé pour des communications privées et sans trace.

#Fonctionnalités
Messagerie instantanée privée en réseau local.
Cryptage des messages pour une sécurité optimale.
Connexions anonymes sans identifiants.
Tranfers des fichiers.
Interface intuitive et réactive.

#Technologies utilisées
Python : Backend pour la gestion des communications.
React : Frontend pour une interface utilisateur dynamique.
TCP/IP : Protocoles pour les échanges réseau.
Bibliothèques : Flask (backend), Axios (frontend).
SGBD : PostgreSQL
